02 / Research agent

A pipeline with a human boundary.

  1. Assigned apps
  2. Discovery
  3. Official-source retrieval
  4. Structured extraction
  5. Evidence checks
  6. Deterministic sample
  7. Human verification
  8. Correction log
  9. Verified projection
  10. Pattern analysis

The Python pipeline used a structured schema and OpenAI strict JSON-schema extraction, preferred official sources, and checked evidence support. The initial discovery path fell back to assigned seed documentation after Composio authentication failed. Failed extraction produced explicit unknowns, rather than guessed capabilities.

First-pass runs were frozen. A deterministic sample (seed 42) selected 20 apps and 40 claims before judgments. Human review confirmed source identity and claim support; corrections were logged separately. A conservative verified projection then supported bounded pattern analysis.

03 / Composio contribution

Live search augmented the research.

The initial authentication failed because the wrong key type was used. After using a valid Composio Platform Project API key, live toolkit inspection selected composio_search and action COMPOSIO_SEARCH_TAVILY, observed version 20260903_00.

Eight successful live searches ran in a separate augmentation checkpoint. It preserved the frozen first pass. This was a separate research path; it does not establish that all 100 apps were researched through Composio.

09 / Limits of this evidence

Uncertainty is part of the result.

  • Only 44/700 critical claims independently checked; 656/700 remain unresolved. The majority of the 100-app dataset remains unverified at claim level.
  • No app row is fully verified: 22 partially resolved, 78 entirely unresolved across seven critical fields.
  • API breadth is unknown for all 100 apps.
  • Five sampled claims remain unclear; no pending sample claims.
  • No live integrations were executed end-to-end. Documented buildability is not integration-test proof.
  • Category ranking is unsupported; reviewed-subset patterns cannot establish population prevalence.
  • Final verified judgments were supplied during verification and were not independently re-audited later.
